## `systemStyle(_:)` presets

Probe: `/tmp/aemisdr-probe/abi.m`, same build, calls `settingsForStyle:` the way `perform(_:with: Int)` does
(an `NSNumber` argument) and through a typed `(id, SEL, long)` IMP, styles 0, 1, 2, 4, 6, 10.

- Via the `perform` shape, every style: `_UIBackdropViewSettingsUltraLight`, radius 20, and UIKit logs
  `unsupported style constant: 262227050` (the tagged pointer's bits). Both runtimes.
- Typed: 0 → `…Light` 30, 1 → `…Dark` 20, 2 → `…Blur` 30; 4, 6, 10 → unsupported → `…UltraLight` 20.

**CONFIRMED defect, twice**: the ABI is wrong, and `UIBlurEffect.Style` raw values are not settings
constants. Every iOS preset is the same configuration today. ADR-0002, roadmap 0002.

## KVC failure modes

Same probe. `[UIScreen valueForKey:@"_aemiDefinitelyMissing"]` → **throws `NSUnknownKeyException`**.
`[NSObject setValue:forKeyPath:@"requestedValues"]` → **throws**. `CAFilter` and `CALayer` `setValue:forKey:`
with an unknown key → **no throw** (silently stored). So `UIScreen.displayCornerRadius` can crash a host
at view init, and a renamed `CABackdropLayer` key is a silent no-op. Roadmap 0003.

## Interned names cost per read

Probe: `/tmp/interned-probe/main.swift`, `SI` and `_SIGen` copied verbatim from Aemi
`Sources/InternedStrings/StringInterner.swift`, the getter written exactly as `@Interned` expands it,
`swiftc -O`, 100,000 reads × 9 rounds, allocations counted through libmalloc's `malloc_logger` hook
(the technique in Aemi's `CAemiTestKitMalloc`). Two runs:

| Read | median | p10 | p90 | allocations/read |
|---|---|---|---|---|
| `@Interned`, 11 B (`inputRadius`) | 155.2 / 155.0 ns | 152 | 196 / 198 | 2.00 |
| `@Interned`, 27 B (`applyRequestedFilterEffects`) | 254.5 / 259.2 ns | 251 / 255 | 308 / 406 | 3.00 |
| `static let`, same expression | 0.9 ns | 0.9 | 0.9 | 0.00 |

**CONFIRMED**: decode-per-read allocates on every access. Single-module approximation of a cross-module
`@inlinable` call, so the absolute ns are owed a probe through the real package. ADR-0003.

## Shader tool pipe

Probe: `/tmp/interned-probe/pipe.swift`, `Process` + `Pipe` in the same order as
`MetalCompilerTool.execute` (`waitUntilExit()` then `readDataToEndOfFile()`), child `head -c N /dev/zero`,
`timeout 5`. 16,000 and 65,536 bytes: complete. **65,537 and 200,000: hang.** CONFIRMED. Roadmap 0009.

## Mask image size

Probe: `/tmp/interned-probe/mask.swift`, macOS, a linear-sRGB `CIContext` like `maskContext`, 1206×2622:
default `createCGImage` → 32 bpp, 12.2 MiB. `.A8` with nil colour space → nil. `.L8` linear gray →
8 bpp, 3.0 MiB, no alpha. With `countLimit = 32` and no cost limit, ~390 MiB worst case. Whether CA reads a
1-byte mask on iOS is OPEN. Roadmap 0007.
