# Capture retry and foreground state

Date: 2026-10-22

The capture audit identified two independent failures. An exhausted capture ring cached the new content signature even
though no texture had been delivered, so the unchanged scene was never retried when a slot became free. Foregrounding
returned before clearing the lifecycle pause flag when continuous capture was disabled, stranding a subsequently enabled
link. Reproduction also exposed a third failure: `captureOnce` marked a failed first attempt as captured.

## Changes

- Commit the signature and `hasCaptured` only after a texture has actually been produced, in either capture backend.
- Clear lifecycle pause state before deciding whether a continuous link currently needs resuming.
- Inject link construction and refresh-rate policy for deterministic lifecycle tests without relying on power or thermal
  state. The real path remains the default.
- Exercise the real three-slot capture ring, preserving its leases through exhaustion and releasing one before retrying.

## Verification

The first test setup did not attach its views to a visible window; that failure was rejected as evidence. An attached
window subsequently reproduced delivery staying at three instead of four. A device-pending layer stand-in is necessary
because the simulator supplies a default Metal device eagerly.

All three regressions failed against the old implementation. The foreground test also retains an already-continuous
positive control. After repair, the full iPhone 18 Pro / iOS 27.2 simulator package test plan passed: 160 test cases,
222 runs including parameters, zero failures and zero skips (`capture-all-green.xcresult`).

Regressions: `foregrounding before continuous capture is enabled does not strand a later display link`,
`a capture dropped because every slot is held is retried when a slot becomes available`,
`a first capture without a Metal device does not mark the source as captured`.

The content signature itself still does not describe every visible mutation. This repairs the transaction and lifecycle;
it does not close roadmap 0006 or establish a sound visual-invalidation scheme.
