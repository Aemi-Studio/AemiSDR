# Diary — 2026-10-22 (04)

## Closing the circular SDF Lipschitz proof and circular arc optical properties

Roadmap 0018 called for closing the outstanding 1-Lipschitz property of the circular rounded box signed distance field.
A monolithic non-linear real arithmetic query returned `unknown` in Z3, and earlier work split the problem across
sign cases while leaving the corner-to-corner regions unproven.

### Circular SDF global 1-Lipschitz theorem

`Verification/Proofs/circular-sdf.smt2` closes the proof across all 16 region pairs in the real domain:
- Reverse triangle inequality `|d(p) - d(q)| <= ||max(dx,0) - max(qx,0)||` reduces the distance difference to the
  projection onto the corner offsets.
- Componentwise absolute contraction `|abs(x) - abs(y)| <= |x - y|` handles the reflection into the first quadrant.
- A Cauchy-Schwarz / inner-product lemma `x u + y v <= ||(x,y)|| ||(u,v)||` proves reverse Euclidean contraction:
  `(||p|| - ||q||)^2 <= ||p - q||^2`.
- Sharpness witnesses confirm the 1-Lipschitz bound cannot be tightened: on straight edges and corners, the Lipschitz
  ratio achieves exactly 1.
- Negative controls confirm the solver refutes false Lipschitz bounds (e.g. attempting to prove L < 1).

### Circular-arc refraction properties

`Verification/Proofs/circular-arc.smt2` proves the real-number properties of the circular-arc refraction model:
- The pull function `P(d) = A * (1 - sqrt(t * (2 - t)))` with `t = clamp(d / H, 0, 1)` is strictly bounded in `[0, A]`.
- Endpoints are exact: `P(0) = A` at the outer rim, and `P(d) = 0` for all `d >= H`.
- Monotonicity: `P(d)` is non-increasing for all `d >= 0`.
- Sensitivity and continuity: `P` is continuous on `[0, inf)`, and away from the extreme rim `d = 0` has finite derivative
  bounded by `-A / H`.

### Proof harness hardening

Following independent audit recommendations, `FormalProofSupport.swift` now rejects:
- Solver non-zero exit codes (`Failure.unsuccessfulExit`).
- Solver output containing errors, timeouts, or unknowns (`Failure.invalidOutput`).
- Proof specifications without both `sat` and `unsat` expected verdicts (enforcing negative controls on every proof).
- Malformed source pins or non-hex digests.

Regression: `a proof gives exactly the answers it declares`, `a proof models the source function as it is now`,
`solver error after a verdict is rejected`, `matching verdicts cannot hide a nonzero exit`,
`abnormal termination rejects matching verdicts`, `missing or malformed pins reject a proof`,
`a proof requires a negative control`.
