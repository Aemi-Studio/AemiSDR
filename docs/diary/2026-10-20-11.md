# Diary — 2026-10-20 (11)

## Reading native glass from the shipped shader

Glass Lab gave the first honest number: **7% similarity** on a dot grid, native `regular` glass against the lens. Native
blurs the backdrop over about 80 pt and tints it by about 53% white; the lens leaves it sharp. A parameter search could not
close that, so the investigation moved from pictures to the code.

| Claim | Probe | Verdict |
|---|---|---|
| The runtime ships the glass shaders | `strings` on `QuartzCore.framework/default.metallib` | **CONFIRMED**: `glass_foreground`, `glass_background_*`, `sdf_*`, `brim_*`, `rim_outline` |
| The library can be read back | `air-objdump -d` | **CONFIRMED**: 9 MB of IR, 228 shaders, names and uniform offsets intact |
| The host GPU runs Apple's library | `makeLibrary(URL:)` then a pipeline with `sdf_filter_vert_lpf` | **CONFIRMED** on an M2 Pro |
| The corner is a circle | decode `supercircle_sdf` | **REFUTED**: extent `1.528665 r` with a fitted cubic in `min/max` |
| My decoding of the field is right | port it, render both with the same random scenes, compare pixels | **CONFIRMED**: largest difference 9e-4 in modes 1, 3, 4, 5 |
| The comparison can fail | six mutations of the port | **CONFIRMED**: 0.15 to 0.96 each |
| A positive radius can be a squircle in mode 5 | first run left the squircle untested (positive radii always blend to a circle) | **REFUTED by the mutation**; signed radii added, the sign picks the curve |

My first mutation run printed the wrong columns and the first sign test did not apply (BSD `sed -i` needs a suffix). Both
looked like passes. Each was re-run with the output read directly before anything was concluded.

Written down in ADR-0007. Not yet done: adopting the geometry in the lens (roadmap 0019), the background pass, and the
CPU side that fills the uniforms from a `UIGlassEffect`. Installed for this: a Python venv (numpy, Pillow, scipy, sympy) at
`~/Library/Caches/aemisdr-tools/venv`.

A licensing question for the owner: the reference reproduces Apple's constants and structure to match its output. It is
documented as measured mathematics and the binary is never copied, but whether a verbatim-equivalent port belongs in an MIT
repository is a decision, not a technicality.

## REA on the CPU side (inconclusive)

`ipsw dyld extract` pulled QuartzCore (5.3 MB, arm64, sha256 `5ff7fe27…`) out of the simulator cache and REA opened it
(Hopper). `search_strings` found every glass entry-point name (`glass_foreground_sdf` at `0x1c3ae15bc`), and `xrefs` led to a
`CFString` constant (`0x2225473c0`) with **no further resolved references**: the code reaches it through ADRP pairs that the
analysis did not resolve in a cache-extracted image. So who fills the uniforms from a `UIGlassEffect` is still unknown.
The next attempt is dynamic: capture the real uniform buffers (Frida or a Metal frame capture of the simulator) for known
`UIGlassEffect` settings, which would also give the blur, tint and refraction parameters directly.
