# Diary — 2026-10-20 (10)

## The shader tool becomes testable, and the shipped library is tested

`MetalCompilerTool` was one 346-line `main.swift`, so none of it could be tested. The logic moved to a `MetalCompilerCore`
library (argument parsing, the deployment floor, output confinement, `DEVELOPER_DIR` sanitising, the `xcrun` arguments, the
subprocess runner) and `main.swift` is three lines.

| Claim | Probe | Verdict |
|---|---|---|
| A long compiler error cascade deadlocks the build | tests print 65,536 / 65,537 / 200,000 / 1,000,000 bytes under a 20 s watchdog | **CONFIRMED** red at 65,537, 200,000 and 1,000,000 (watchdog fired), green after drain-then-wait |
| The plugin compiles for iOS 14 / macOS 11 | read the plugin; compile the same source at both floors | **CONFIRMED**; the library differs (macOS 17,432 vs 20,088 bytes), so the floor changes the code |
| Compiling for the real floor changes what is drawn | render 8 lens variants with the shipped library, the 11.0 library and the run-time source | **REFUTED**: 0/255 largest channel difference in all three |
| That test can fail | a library built from a source with the quartic falloff times 0.9 | **CONFIRMED**: 7 of 8 variants fail by 65 to 73/255 (the eighth uses another falloff) |
| An output outside the root is reported as a missing argument | test expects `outputOutsideAllowedRoot` | **CONFIRMED**, fixed |
| Compiling for the floor is faster | interleaved GPU timing, 2048x2048, 40 draws, blending on | **NOT RESOLVED**: every variant reads 0.015 to 0.04 ms with a spread above the median, so it measures launch overhead. The benchmark was removed rather than shipped. No performance claim is made. |

`ShippedShaderTests` is the first test of the artifact users run; the others compile the source at run time. It finds the library
in the resource bundle, or at `AEMI_SHIPPED_METALLIB`, which is how the mutant and the old floor were checked.

Not done: a GPU-time comparison that resolves. The scene needs a heavier workload (a full-screen lens, many frames) or a signpost
capture before a speed claim about the floor is made.
