# Diary — 2026-10-22 (05)

## Render attempt gating on unchanged layout and bounded in-flight drawables

Roadmap 0005 called for eliminating main-thread stalls and redundant rendering passes in `LiquidLensUIView`.

### Render gating on unchanged layout

Previously, `LiquidLensUIView.layoutSubviews()` called `renderIfNeeded()` unconditionally on every pass to handle
late-arriving source textures, causing 100 layout passes on static content to attempt 100 renders.

- Introduced `needsRender: Bool` flag, initialized to `true`.
- Gated `renderIfNeeded()` behind `guard needsRender else { return }`.
- Set `needsRender = true` when the source texture changes, configuration changes, or `syncDrawableMetrics()` detects a
  size or contents scale change.
- Cleared `needsRender = false` only after a drawable is successfully acquired and submitted to the GPU. Late sources or
  zero-sized views retain `needsRender = true` so the first valid layout renders as before.

Regression: `unchanged layout passes do not trigger redundant render attempts` verifies that 100 layout passes dispatch
only the initial render attempt, and that updating the configuration re-enables rendering on the next layout pass.
`resizing the view marks it as needing a render` verifies size changes re-trigger rendering.

### Bounded in-flight drawables

- Tracked GPU submissions with an atomic counter `inFlightDrawables: Atomic<Int>`.
- When in-flight drawables reach `metalLayer.maximumDrawableCount - 1`, subsequent render calls skip rather than blocking
  the main thread in `metalLayer.nextDrawable()`.
- On completion of the Metal command buffer, `inFlightDrawables` is decremented and any pending `needsRender` request is
  scheduled back to the main thread.

### Clean corner resolution priority on iOS 27

`DisplayCornerSources.read(scene:screen:)` now queries `UITraitCollection.displayCornerRadius` first, falling back to
`UIScreen._displayCornerRadius` only if absent. This matches the priority ladder in `DisplayCornerRadii.resolve` and
avoids unnecessary lookup of the deprecated screen selector on iOS 27.
