# Diary — 2026-10-22 (06)

## Variable blur and alpha mask layout gating

Roadmap 0008 addressed redundant filter setup and layer mask reassignments in `VariableBlurUIView` and `AlphaMaskUIView`.

### Elimination of filter reassignments on unchanged layout

- Added `appliedMaskKey: MaskCacheKey?` and `installedRadius: CGFloat?` to `VariableBlurUIView`.
- Gated `setupVariableBlurFilter()` and mask application so that layout passes with unchanged size, scale, radius, and
  mask parameters perform no Core Animation filter array clearing or reassignments.
- When `maxBlurRadius` is modified on an existing filter, `radiusParam` is updated in place without clearing the filter
  array.
- Added `appliedMaskKey` to `AlphaMaskUIView` to skip redundant `layer.mask` assignments on unchanged layout passes.
- Wrapped `applyMaskImage` in `CATransaction` with actions disabled (`setDisableActions(true)`) to prevent unintended
  implicit layer animations during view resizes (defect 5).

Regression: `variable blur does no filter reassignments on unchanged layout`,
`alpha mask does not reapply mask on unchanged layout`. Both were confirmed red before the gating logic was applied.
