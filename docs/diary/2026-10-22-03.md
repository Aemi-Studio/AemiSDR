# Diary — 2026-10-22 (03)

## Component size constraints on rim refraction and the interactive tuner

Thin shapes such as a 40 pt high capsule previously evaluated rim pulls with the default 20 pt height and 60 pt
amplitude. At 40 pt height, the top and bottom edge refractions met at the centerline while still exerting strong pull,
colliding and distorting the interior rather than preserving the flat central backdrop seen in native glass.

### Refraction bounded by component size

Refraction is now bounded by component geometry for all shapes (rectangles, capsules, circles, and arbitrary paths):
- Edge falloff height and Gaussian body width are clamped to at most half the shorter component dimension.
- Maximum total channel displacement, including chromatic extremes `(1 ± chromatic)`, is bounded by that same half-size.
- Circular arcs reach zero pull before opposing edges can collide, guaranteeing that thin shapes leave their central axis
  undistorted.
- Large shapes retain the full calibrated native clear pull (e.g. 60 pt pull over 20 pt height).

Regression: `every shape caps pull height and channel displacement to half its shorter dimension` tests rectangles,
per-corner rounded shapes, capsules, circles, and paths across 1x, 2x, and 3x scales.

### Interactive Glass Tuner (macOS & iPad Simulator)

Delivered `Examples/GlassTuner` running on macOS and iPad Simulator (iOS 27.2 reference). It renders native clear glass
side by side with AemiSDR over calibrated test backdrops (grid, dots, checkerboard, stripes, solid tones), with full
parameter controls, Swift code export, and live GPU/readback millisecond timings. Intermediate frames are delivered
during drags without freezing.

### Path snapshot immutability & still image renderer

- `GlassShape.path` now wraps an immutable `GlassPath` snapshot, preventing mutations to a caller's `CGMutablePath` from
  altering cached distance fields or in-flight renders.
- `ClearGlassImageRenderer` provides dedicated asynchronous rendering off the main thread with memory limits and
  cancellation support.

Verification: full suite passes (185 AemiSDR tests across 34 suites + GlassTuner suite).
